Privacidade e segurança

100% no seu computador

Este programa não envia nada para nenhum servidor. Suas fotos, legendas, nomes de arquivo e ajustes nunca saem do navegador.

Mecanismos ativos

• Content-Security-Policy com connect-src 'none': o navegador bloqueia qualquer envio de dados (fetch, XHR, formulário, WebSocket).
• Sem scripts externos (script-src 'self') e sem código embutido — nada de terceiros roda aqui.
• Toda imagem adicionada é redesenhada internamente: metadados (EXIF/GPS), perfis e qualquer conteúdo escondido são removidos. Arquivos que não são imagem real são recusados.
• Projetos abertos (.json) passam pela mesma limpeza; valores fora do padrão são corrigidos.
• O servidor não executa PHP nesta pasta e não tem contato com banco de dados.

Onde ficam os dados

Só na área privada deste navegador (IndexedDB), neste dispositivo. Para backup use Salvar projeto.
Sobre

Polaroide Studio — ferramenta para montar polaroides em folhas prontas para impressão (PDF, PNG ou impressão direta), com formatos reais, corte profissional e ajustes de foto.

Projeto de portfólio de Carlos Avelino Correa — github.com/avelinocarloscorrea.

Funciona offline. Nenhum dado é coletado.
